# C# Learning

This repository contains my C# and .NET practice implementations while learning the language through small programs and practical examples.

## Topics Covered

- C# program structure
- .NET runtime, CLR, IL and JIT
- Value types and reference types
- Boxing and unboxing
- `var`, `object` and `dynamic`
- String interpolation
- Nullable value types and nullable reference types
- Null handling using `?.`, `??` and `??=`
- Type casting
- `Parse()` and `TryParse()`
- Pattern matching
- Properties
- Constructors and `this`
- Access modifiers
- Basic usage of `base`
- Input validation
- Encapsulation through a simple Bank Account program
